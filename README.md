# 🐾 AgroVet - Sistema de Gestión de Servicios Veterinarios y E-Commerce

**AgroVet** es una plataforma web integral diseñada para la gestión de servicios veterinarios de campo, agendamiento de citas, control censal sanitario y venta en línea de productos pecuarios.

---

## 🚀 Características Principales

* **Autenticación y Roles:** Registro de usuarios e inicio de sesión seguro con contraseñas encriptadas y roles diferenciados (Cliente/Productor y Administrador).
* **Gestión de Animales:** Registro de mascotas y ganado (bovino, equino, porcino, avícola, entre otros) con historial y datos clínicos.
* **Agendamiento de Citas:** Reserva de consultas veterinarias con validación automática de días hábiles y horarios disponibles.
* **Catálogo y Carrito de Compras:** Tienda virtual de productos agrícolas con control de stock en tiempo real y carrito persistente (`localStorage`).
* **Panel de Administración:** Gestión centralizada para el control de usuarios, productos, stock y estados de citas (*Pendiente*, *Confirmada*, *Completada*, *Cancelada*).
* **Diseño Responsive:** Interfaz adaptable a dispositivos móviles, tablets y de escritorio, optimizada con atajo de contacto directo vía WhatsApp.

---

## 🛠️ Tecnologías Utilizadas

* **Backend:** PHP 7.4+
* **Base de Datos:** MySQL / MariaDB
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla), Bootstrap 5.3
* **Entorno Servidor:** Apache (XAMPP)
